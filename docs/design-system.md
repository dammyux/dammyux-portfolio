# Design System & Token Specification

## 1. Color Palette

### Dark Mode (Primary Default)
- **Background Base:** `#090a0c`
- **Surface Level 1:** `#111317`
- **Surface Level 2 (Raised):** `#181b20`
- **Border Default:** `#22262e`
- **Primary Text:** `#f5f6f8`
- **Muted Text:** `#9ca3af` / `#6b7280`
- **Brand Accent Green:** `#00e599` / `#10b981`
- **Accent Glow:** `rgba(0, 229, 153, 0.15)`

### Light Mode
- **Background Base:** `#fbfbfa`
- **Surface Level 1:** `#ffffff`
- **Surface Level 2 (Raised):** `#f4f4f5`
- **Border Default:** `#e5e7eb`
- **Primary Text:** `#111827`
- **Muted Text:** `#4b5563`
- **Brand Accent Green:** `#059669` (for enhanced AA contrast)

## 2. Typography
- **Primary Font Family:** Inter (`next/font/google`)
- **Scale:**
  - Hero Display: `4xl` (Mobile) to `7xl` (Desktop)
  - Section Headlines: `3xl` to `5xl`
  - Subheadings: `xl` to `2xl`
  - Body Text: `sm` to `base` (Leading relaxed: `1.6`)
  - Metadata / Pills: `xs` / `11px` (Mono / Uppercase tracking)
