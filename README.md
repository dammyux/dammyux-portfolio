- 🌑 **Dark-First Theme System:** Deep black surfaces with refined emerald/mint green accents (`#00e599`) and seamless Light mode switching.
- 🧊 **Interactive 3D Hero:** Custom Three.js composition with cursor parallax, touch interaction, and theme-synchronized lighting.
- ⚡ **Blazing Fast Performance:** Powered by Next.js App Router, TypeScript, and Tailwind CSS.
- 🎬 **AI Video Showcase:** Dedicated media player support for cinematic AI commercials and vertical social ads.
- 🎚️ **Interactive Before/After Slider:** Visual transformation comparison component for redesign case studies.
- 📱 **Fully Responsive:** Fluid navigation, mobile drawer with Framer Motion, and touch-optimized interactions.
- 🔍 **SEO & Accessibility Ready:** Dynamic XML sitemap, robots.txt, JSON-LD structured schema, and `prefers-reduced-motion` support.

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
## 📁 Site Structure

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
- `/` — Homepage (Hero 3D, Selected Work, Disciplines, Pricing, Proof, Short About, Final CTA)
- `/about` — About (Philosophy, Background, Skill Matrix, Tools, CV Download)
- `/services` — Services & Pricing (Full 3-pillar catalog, transparent tiers, FAQ accordion)
- `/work` — Work Portfolio (Filterable project grid)
- `/work/[slug]` — Dynamic Project Detail Pages (Overview, Challenge/Solution, Before/After Slider, Tech Stack, Metrics)
- `/case-studies` — Case Studies (In-depth visual transformation flows)
- `/contact` — Contact Hub (Direct WhatsApp, Calendly, Email, Fiverr, Upwork)
